# Frontend

This directory is reserved for the PathSnap evaluator frontend.

The frontend implementation is maintained by the UI team member and will be added here separately.

The frontend should:
- Connect to the FastAPI backend.
- Display the 10 evaluator trips.
- Allow trip selection and prediction requests.
- Visualize GPS observations and reconstructed routes.
- Display server-generated evaluation metrics.

Backend API documentation: http://localhost:8000/docs
